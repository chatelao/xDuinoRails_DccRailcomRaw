# DCC Waveform Static Analysis Report

## 1. Summary

This report provides a static analysis of the DCC waveform that would be generated by the `SendSpeed.ino` example. The analysis is based on a manual review of the `DCCRailcom.cpp` and `SendSpeed.ino` source files.

The analysis concludes that the `SendSpeed.ino` example, as written, **generates an invalid DCC packet**. The primary issues are incorrect start and end bits, and a mismatched checksum.

## 2. Bit Timings

The `DCCRailcom.cpp` file defines the following pulse widths for DCC bits:

*   **DCC '1'**: 58µs low, followed by 58µs high (Total period: 116µs)
*   **DCC '0'**: 100µs low, followed by 100µs high (Total period: 200µs)

These timings are consistent with the NMRA S-9.1 DCC standard.

## 3. `SendSpeed.ino` Packet Analysis

The `SendSpeed.ino` example attempts to send a 128-step speed command to locomotive address 3 with a speed of 58. The `rawPacket` byte array is defined as follows:

```c++
uint8_t rawPacket[] = {
  0xFF, // Preamble
  0xFC, // Preamble (4 bits) + 0 + Address (3) - first 3 bits
  0x1F, // last 5 bits of address + 0 + Command (63) - first 2 bits
  0xDE, // last 6 bits of command + 0 + Speed (58) - first 1 bit
  0x82, // last 7 bits of speed + 0
  0x8A, // Checksum (10)
  0x80  // End bit (1) + 7 padding bits
};
```

### 3.1. Bitstream Decoding

Decoding this byte array into a bitstream results in the following 52-bit sequence:

`11111111 11111100 00011111 11011110 10000010 10001010 10000000`

### 3.2. Packet Structure Analysis

According to the DCC standard, a packet should be structured as follows:

`Preamble | 0 | Address (8) | 0 | Data (8) | 0 | Data (8) ... | 0 | Checksum (8) | 1`

When applying this structure to the decoded bitstream, we find the following issues:

| Component      | Expected Bits | Actual Bits   | Correct? | Notes                                                                                                                                                                                            |
| :------------- | :------------ | :------------ | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Preamble**   | `11111111 11111111` | `11111111 111111` | No       | The preamble is only 14 bits, not the intended 16.                                                                                                                                               |
| **Start Bit**  | `0`           | `0`           | Yes      |                                                                                                                                                                                                  |
| **Address**    | `00000011`    | `00001111`    | No       | The address is decoded as 15, not 3.                                                                                                                                                             |
| **Start Bit**  | `0`           | `1`           | No       | **Critical Error:** The start bit is a '1' instead of a '0'. This will cause decoders to reject the packet.                                                                                       |
| **Command**    | `00111111`    | `11011110`    | No       | The command byte is incorrect.                                                                                                                                                                   |
| **Start Bit**  | `0`           | `1`           | No       | **Critical Error:** The start bit is a '1' instead of a '0'.                                                                                                                                     |
| **Speed**      | `00111010`    | `00000101`    | No       | The speed byte is incorrect.                                                                                                                                                                     |
| **Start Bit**  | `0`           | `0`           | Yes      |                                                                                                                                                                                                  |
| **Checksum**   | `00001010`    | `00101010`    | No       | The transmitted checksum (42) does not match the expected checksum (10).                                                                                                                           |
| **End Bit**    | `1`           | `0`           | No       | **Critical Error:** The end bit is a '0' instead of a '1'. This will cause decoders to reject the packet.                                                                                         |

## 4. Conclusion

The `rawPacket` data in `SendSpeed.ino` is incorrectly constructed. The comments in the source file describe a valid DCC packet, but the byte array itself does not match this description. This leads to an invalid DCC packet being generated, which would be rejected by any compliant DCC decoder.
